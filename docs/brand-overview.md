# LinkDeck Brand Overview

This document summarizes the current public LinkDeck brand direction.

The internal brand guide contains additional working notes and asset-management details. This public version focuses only on material intended for consistent external use.

## Brand positioning

LinkDeck is a compact hardware product focused on digital identity, NFC sharing and connected experiences.

The brand should feel:

- Compact
- Connected
- Technical
- Friendly
- Premium
- Maker-oriented
- Clear and practical

The visual identity should avoid becoming overly cyberpunk, childish or visually noisy.

## Core palette

The current standard LinkDeck palette is:

- **LinkDeck Black:** `#0B0F14`
- **Graphite:** `#171C24`
- **Cyan:** `#22D3EE`
- **Electric Blue:** `#0EA5E9`
- **White:** `#F8FAFC`

Dark graphite/black should dominate. Cyan and electric blue are accents rather than full-surface background colors.

## Typography direction

Preferred typography:

- **Space Grotesk** — headings and major brand statements
- **Inter** — body copy, UI labels and documentation
- **JetBrains Mono** — technical values, diagnostics and code-like content

Embedded-device typography may use technically suitable alternatives while preserving the same hierarchy and character.

## Ray — LinkDeck mascot

**Ray** is a manta ray representing connectivity, movement and wireless sharing.

Public visual direction:

- Graphite / matte-black body
- Cyan and electric-blue highlights
- Simple expressive eyes
- Subtle contactless/NFC detail
- Clean 2D, sticker-like silhouette
- Approachable without becoming childish

Ray works best in community-facing content, welcome states, setup guidance, empty states and milestone moments.

The functional product UI and enclosure should remain visually restrained rather than mascot-driven.

## Public tagline

> Compact hardware for digital identity, NFC sharing and connected experiences.

## Wordmark status

Use the product name consistently as **LinkDeck** with capital **L** and **D**.

The final production logo/wordmark lockup is **not yet frozen**. Concept artwork should not be treated as final manufacturing artwork until an approved production identity exists.

## UI relationship

The public product UI direction follows the same identity:

- Near-black / graphite surfaces
- Cyan primary actions
- Electric-blue secondary accents
- White primary text
- Restrained glow and animation
- AMOLED-friendly dark layouts

See the [UI/UX Overview](ui-ux-overview.md) for the current public interaction direction.

## Image style

Preferred product imagery uses:

- Dark neutral or studio backgrounds
- Realistic materials and proportions
- Restrained cyan/blue lighting
- Clean compositions
- Believable consumer-electronics presentation

Avoid invented hardware details, excessive neon, random ports, toy-like proportions or misleading renders presented as finished hardware.

## Tone of voice

Public LinkDeck communication should be:

- Concise
- Technically credible
- Approachable
- Transparent about prototype status
- Confident without exaggerating capabilities

English is the primary public language. Portuguese may be used where appropriate.

## Public assets

Public-safe material may include approved:

- Logos/wordmarks
- Ray mascot artwork
- Avatars
- Banners
- Social graphics
- Selected UI previews

Engineering-sensitive imagery remains private when it reveals production CAD, internals, manufacturing data, provisioning/security details or supplier-sensitive information.
